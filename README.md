# Personal Budget System

The personal budgeting system controls how the money available to the user is spent.

The program should support the following functionalities:
- insertion/removal of transactions;
- balance inquiry;
- checking the validity of the budget;
- checking the possible expense dates.

## Description

This repository contains sample code produced during Scientific Computing classes.

These samples are intended to support students in implementing the program within the context of their academic work.

## Getting Started

### Dependencies

* There is no dependencies

### Installing

Install the Portugol Studio tool or use the version available on the [web](https://portugol.dev/) to run the program.

### Executing program

* Load the sample into Portugol Studio and run it.
